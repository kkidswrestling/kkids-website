# Notes for maintaining this site

This file is public (the repo is public and every file is published), so write notes that anyone could read.

Owner: Coach Joe Provini (head coach). He asks for updates in plain language; make the change, rebuild, check, and push.

- Static site on GitHub Pages, generated by `python3 tools/build.py` from `data/`. Never hand-edit generated HTML.
- Pages live in folders (`high-school/index.html`, ...) to keep the old Wix URLs. All links are relative so the site works at both the github.io test address and the custom domain. `404.html` uses root-relative links.
- Redirect stubs keep old Wix addresses working: `schedule-1/`, `copy-of-high-school/`, `copy-of-high-school-1/`, `coaches/`.
- Photos: catalog in `data/photos.toml`, processed by `tools/images.py` into `assets/img/photos/` (WebP sizes + one JPEG). Only use a photo in a season-specific spot if its `season` matches. Several banquet-program photos were reused from earlier programs; check before using any new one.
- Credit watermarked photos (Aaron Morekin). Don't use newspaper photos or social-media screenshots.
- Youth (K-6): no names next to faces.
- Official logo: assets/img/logo-*.png (orange N with KONKRETE KIDS bar). Use it for the brand mark and icons; never redraw it.
- Hall of Champions counts and multi-time honors are computed from the CSV lists. The lists match the programs' own district/regional/state lists line for line (checked against the 2021-22 program in Oct. 2026). The programs' "champions by coach" table doesn't add up to their own lists (e.g., it gives Seth Lisa 14 district / 14 regional; the lists show 16 / 15), so don't use that table's totals. Dave Gilio (8th, 130, 2004) was missing and was added from the 2021-22 and 2022-23 programs. James Hankee (1953 District XI champion, 127) was missing from the programs and was added on Joe's OK (Oct. 20, 2026): Lehigh Valley Wrestling History's District XI finals list and its 1952-53 page ("5 for 8" in the finals, Hankee had the only fall). District XI champions 1948-1993 otherwise match that finals list name for name (spellings differ; ours kept).
- Girls wrestling is a separate program; leave it out.
- Before pushing: build, preview with `python3 -m http.server`, check phone and desktop widths, no sideways scrolling, no console errors.
- Home gym: Pete Schneider Gymnasium (confirmed via Morning Call, Jan. 5, 2024).
