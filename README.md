# Northampton Wrestling website

The website for Northampton Wrestling (Konkrete Kids), northamptonwrestling.org.

Each page is a plain HTML file in this folder:

| File | Page |
|---|---|
| `index.html` | Home |
| `high-school.html` | High School (current season and last season's recap) |
| `schedule.html` | Schedule |
| `junior-high.html` | Junior High |
| `youth.html` | Youth |
| `coaches.html` | Coaching staff and club officers |
| `champions.html` | Hall of Champions (all-time lists and records) |
| `seasons.html` | Past seasons |

Styles live in `assets/site.css` and photos in `assets/img/`.

To change text, open a page, click the pencil icon, edit the words between the tags, and commit. The site updates in a minute or two.
